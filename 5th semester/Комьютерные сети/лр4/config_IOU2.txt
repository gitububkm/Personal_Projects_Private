===========================================
КОНФИГУРАЦИЯ РОУТЕРА IOU2 (c7200)
Коммутатор доступа (Access Switch)
ВАЖНО: Роутер c7200 используется как коммутатор
Интерфейсы: FastEthernet (не Ethernet)
===========================================

СНАЧАЛА ВЫПОЛНИТЕ ЭТИ КОМАНДЫ ОТДЕЛЬНО:
[ОДНА КОМАНДА] enable
  → Вход в привилегированный режим

[ОДНА КОМАНДА] configure terminal
  → Вход в режим глобальной конфигурации

===========================================
ТЕПЕРЬ ВЫПОЛНЯЙТЕ КОМАНДЫ ИЗ ФАЙЛА:
===========================================

[ОДНА КОМАНДА] no ip routing
  → Отключаем маршрутизацию IP на устройстве
  → ВАЖНО: Для работы роутера c7200 как коммутатора нужно отключить IP routing
  → Без этой команды устройство будет работать как роутер, а не как коммутатор

===========================================
БЛОК 1: Создание VLAN 10
(выполняйте все команды подряд)

ЧТО ДЕЛАЕМ: Создаем VLAN 10 на коммутаторе IOU2
ЗАЧЕМ: VLAN 10 нужен для PC1, который подключен к этому коммутатору
       Коммутатор должен знать о VLAN 10, чтобы правильно обрабатывать трафик
===========================================
[БЛОК КОМАНД - ВСЕ ВМЕСТЕ]
vlan 10
  → Создаем VLAN 10
  → Входим в режим настройки VLAN

name VLAN10
  → Даем имя "VLAN10"
exit
  → Выходим из режима настройки VLAN

===========================================
БЛОК 2: Создание VLAN 15
(выполняйте все команды подряд)

ЧТО ДЕЛАЕМ: Создаем VLAN 15 на коммутаторе IOU2
ЗАЧЕМ: VLAN 15 нужен для PC2, который подключен к этому коммутатору
===========================================
[БЛОК КОМАНД - ВСЕ ВМЕСТЕ]
vlan 15
  → Создаем VLAN 15

name VLAN15
  → Имя "VLAN15"
exit

===========================================
БЛОК 3: Настройка порта к IOU1 (Trunk)
(выполняйте все команды подряд)

ЧТО ДЕЛАЕМ: Настраиваем порт Ethernet0/0 в режим Trunk для связи с центральным коммутатором IOU1
ЗАЧЕМ: Через этот порт должен проходить трафик VLAN 10 и 15 к центральному коммутатору
       Trunk позволяет передавать несколько VLAN по одному кабелю
       Без Trunk устройства из разных VLAN не смогут общаться через роутер
===========================================
[БЛОК КОМАНД - ВСЕ ВМЕСТЕ]
interface FastEthernet0/0
  → Переходим в режим настройки порта FastEthernet0/0
  → Это порт, который подключен к центральному коммутатору IOU1
  → На роутере c7200 интерфейсы называются FastEthernet, а не Ethernet

description Connection to IOU1
  → Описание: подключение к IOU1

no shutdown
  → Включаем порт (по умолчанию он может быть выключен)
  → БЕЗ ЭТОЙ КОМАНДЫ порт не будет работать!

switchport trunk encapsulation dot1q
  → Включаем инкапсуляцию 802.1Q для Trunk порта
  → Это стандарт для маркировки VLAN в кадрах Ethernet

switchport mode trunk
  → Переводим порт в режим Trunk
  → Trunk порт передает трафик нескольких VLAN одновременно

switchport trunk allowed vlan 10,15
  → Разрешаем передачу только VLAN 10 и 15 через этот Trunk
  → На этом коммутаторе используются только эти два VLAN
  → Это повышает безопасность - другие VLAN не пройдут
exit
  → Выходим из режима настройки интерфейса

===========================================
БЛОК 4: Настройка порта для PC1 (VLAN 10)
(выполняйте все команды подряд)

ЧТО ДЕЛАЕМ: Настраиваем порт Ethernet0/1 в режим Access для подключения PC1
ЗАЧЕМ: PC1 должен быть в VLAN 10, поэтому порт настраиваем как Access и привязываем к VLAN 10
       Access порт передает трафик только одного VLAN (без тегов)
===========================================
[БЛОК КОМАНД - ВСЕ ВМЕСТЕ]
interface FastEthernet0/1
  → Переходим в режим настройки порта FastEthernet0/1
  → Это порт, к которому подключен PC1
  → На роутере c7200 интерфейсы называются FastEthernet

description PC1 - VLAN 10
  → Описание: PC1 в VLAN 10

no shutdown
  → Включаем порт

switchport mode access
  → Переводим порт в режим Access
  → Access порт предназначен для подключения конечных устройств (компьютеров, принтеров)
  → В отличие от Trunk, Access порт передает трафик только одного VLAN

switchport access vlan 10
  → Привязываем порт к VLAN 10
  → Весь трафик, приходящий на этот порт, будет относиться к VLAN 10
  → PC1 будет находиться в VLAN 10
exit
  → Выходим из режима настройки интерфейса

===========================================
БЛОК 5: Настройка порта для PC2 (VLAN 15)
(выполняйте все команды подряд)

ЧТО ДЕЛАЕМ: Настраиваем порт Ethernet0/2 в режим Access для подключения PC2
ЗАЧЕМ: PC2 должен быть в VLAN 15
===========================================
[БЛОК КОМАНД - ВСЕ ВМЕСТЕ]
interface FastEthernet0/2
  → Порт, к которому подключен PC2
  → На роутере c7200 интерфейсы называются FastEthernet

description PC2 - VLAN 15
  → Описание: PC2 в VLAN 15

no shutdown
  → Включаем порт

switchport mode access
  → Режим Access (для конечных устройств)

switchport access vlan 15
  → Привязываем порт к VLAN 15
  → PC2 будет находиться в VLAN 15
exit

===========================================
СОХРАНЕНИЕ КОНФИГУРАЦИИ
===========================================
ВАЖНО: Сначала выйдите из режима конфигурации командой "exit"

[ОДНА КОМАНДА] exit
  → Выходим из режима глобальной конфигурации
  → Должно появиться IOU2# (привилегированный режим)

[ОДНА КОМАНДА] copy running-config startup-config
  → Сохраняем конфигурацию в постоянную память
  → БЕЗ ЭТОЙ КОМАНДЫ настройки пропадут после перезагрузки!

===========================================
ПРОВЕРКА НАСТРОЙКИ
===========================================
После сохранения можете проверить:
- show vlan brief        (покажет все VLAN и к каким портам они привязаны)
- show interfaces trunk  (покажет Trunk порты)
- show interfaces status (покажет статус всех портов и их режимы)
