===========================================
ИНСТРУКЦИЯ ПО НАСТРОЙКЕ ЛАБОРАТОРНОЙ РАБОТЫ
Вариант 1 - Протоколы локальных сетей
===========================================

РАСПРЕДЕЛЕНИЕ VLAN:
- PC1 → VLAN 10 (IOU2)
- PC2 → VLAN 15 (IOU2)
- PC3 → VLAN 15 (IOU3)
- PC4 → VLAN 20 (IOU3)

IP АДРЕСАЦИЯ:
- VLAN 10: 192.168.10.0/24 (шлюз: 192.168.10.1)
- VLAN 15: 192.168.15.0/24 (шлюз: 192.168.15.1)
- VLAN 20: 192.168.20.0/24 (шлюз: 192.168.20.1)

DHCP ДИАПАЗОН: 192.168.X.10 - 192.168.X.100 для каждого VLAN

===========================================
ПОРЯДОК НАСТРОЙКИ:
===========================================

1. НАСТРОЙКА R1 (РОУТЕР):
   - Откройте консоль R1
   - Скопируйте команды из config_R1.txt
   - Вставьте в консоль и нажмите Enter

2. НАСТРОЙКА IOU1 (Центральный коммутатор):
   - Откройте консоль IOU1
   - Скопируйте команды из config_IOU1.txt
   - Вставьте в консоль и нажмите Enter

3. НАСТРОЙКА IOU2 (Коммутатор с PC1 и PC2):
   - Откройте консоль IOU2
   - Скопируйте команды из config_IOU2.txt
   - Вставьте в консоль и нажмите Enter

4. НАСТРОЙКА IOU3 (Коммутатор с PC3 и PC4):
   - Откройте консоль IOU3
   - Скопируйте команды из config_IOU3.txt
   - Вставьте в консоль и нажмите Enter

5. ПРОВЕРКА РАБОТЫ:
   - На PC1, PC2, PC3, PC4 выполните команду: ip dhcp
   - Проверьте получение IP-адресов
   - Проверьте связность между устройствами

===========================================
ВАЖНО:
===========================================
- Настраивайте устройства в указанном порядке
- После настройки каждого устройства проверьте, что команды применились
- Используйте команду "show vlan brief" на коммутаторах для проверки VLAN
- Используйте "show ip interface brief" на роутере для проверки интерфейсов
