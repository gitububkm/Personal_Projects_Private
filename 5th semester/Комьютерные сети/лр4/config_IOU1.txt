===========================================
КОНФИГУРАЦИЯ РОУТЕРА IOU1 (c7200)
Центральный коммутатор (Core Switch)
ВАЖНО: Роутер c7200 используется как коммутатор
Интерфейсы: FastEthernet (не Ethernet)
===========================================

СНАЧАЛА ВЫПОЛНИТЕ ЭТИ КОМАНДЫ ОТДЕЛЬНО:
[ОДНА КОМАНДА] enable
  → Вход в привилегированный режим

[ОДНА КОМАНДА] configure terminal
  → Вход в режим глобальной конфигурации

===========================================
ТЕПЕРЬ ВЫПОЛНЯЙТЕ КОМАНДЫ ИЗ ФАЙЛА:
===========================================

[ОДНА КОМАНДА] no ip routing
  → Отключаем маршрутизацию IP на устройстве
  → ВАЖНО: Для работы роутера c7200 как коммутатора нужно отключить IP routing
  → Без этой команды устройство будет работать как роутер, а не как коммутатор

===========================================
БЛОК 1: Создание VLAN 10
(выполняйте все команды подряд)

ЧТО ДЕЛАЕМ: Создаем виртуальную локальную сеть с номером 10
ЗАЧЕМ: VLAN 10 нужен для изоляции трафика PC1 от других устройств
       Это логическое разделение сети на сегменты
===========================================
[БЛОК КОМАНД - ВСЕ ВМЕСТЕ]
vlan 10
  → Создаем VLAN с номером 10
  → Входим в режим настройки этого VLAN

name VLAN10
  → Даем VLAN понятное имя "VLAN10"
  → Это помогает администратору понимать назначение VLAN
exit
  → Выходим из режима настройки VLAN

===========================================
БЛОК 2: Создание VLAN 15
(выполняйте все команды подряд)

ЧТО ДЕЛАЕМ: Создаем VLAN 15
ЗАЧЕМ: VLAN 15 нужен для PC2 и PC3
===========================================
[БЛОК КОМАНД - ВСЕ ВМЕСТЕ]
vlan 15
  → Создаем VLAN 15

name VLAN15
  → Имя "VLAN15"
exit

===========================================
БЛОК 3: Создание VLAN 20
(выполняйте все команды подряд)

ЧТО ДЕЛАЕМ: Создаем VLAN 20
ЗАЧЕМ: VLAN 20 нужен для PC4
===========================================
[БЛОК КОМАНД - ВСЕ ВМЕСТЕ]
vlan 20
  → Создаем VLAN 20

name VLAN20
  → Имя "VLAN20"
exit

===========================================
БЛОК 4: Настройка порта к роутеру R1 (Trunk)
(выполняйте все команды подряд)

ЧТО ДЕЛАЕМ: Настраиваем порт Ethernet0/0 в режим Trunk для связи с роутером
ЗАЧЕМ: Trunk порт передает трафик нескольких VLAN по одному кабелю
       Роутер должен получать трафик из всех VLAN (10, 15, 20) для маршрутизации
       Без Trunk роутер не сможет обрабатывать трафик из разных VLAN
===========================================
[БЛОК КОМАНД - ВСЕ ВМЕСТЕ]
interface FastEthernet0/0
  → Переходим в режим настройки порта FastEthernet0/0
  → Это порт, который подключен к роутеру R1
  → На роутере c7200 интерфейсы называются FastEthernet, а не Ethernet

description Connection to R1
  → Добавляем описание порта (для удобства администрирования)
  → Помогает понять, куда подключен этот порт

no shutdown
  → Включаем порт (по умолчанию он может быть выключен)
  → БЕЗ ЭТОЙ КОМАНДЫ порт не будет работать!

switchport trunk encapsulation dot1q
  → Включаем инкапсуляцию 802.1Q (dot1q) для Trunk порта
  → Это стандарт для маркировки VLAN в кадрах Ethernet
  → Каждый кадр получает тег с номером VLAN

switchport mode trunk
  → Переводим порт в режим Trunk
  → Trunk порт может передавать трафик нескольких VLAN одновременно
  → В отличие от Access порта, который передает только один VLAN

switchport trunk allowed vlan 10,15,20
  → Разрешаем передачу только VLAN 10, 15 и 20 через этот Trunk
  → Это повышает безопасность - другие VLAN не пройдут
  → Можно было бы указать "all", но лучше ограничить список
exit
  → Выходим из режима настройки интерфейса

===========================================
БЛОК 5: Настройка порта к IOU2 (Trunk)
(выполняйте все команды подряд)

ЧТО ДЕЛАЕМ: Настраиваем порт Ethernet0/1 в режим Trunk для связи с коммутатором IOU2
ЗАЧЕМ: IOU2 подключен к IOU1, и нужно передавать трафик VLAN 10 и 15 между ними
       Trunk позволяет передавать несколько VLAN по одному кабелю
===========================================
[БЛОК КОМАНД - ВСЕ ВМЕСТЕ]
interface FastEthernet0/1
  → Переходим в режим настройки порта FastEthernet0/1
  → Это порт, который подключен к коммутатору IOU2
  → На роутере c7200 интерфейсы называются FastEthernet

description Connection to IOU2
  → Описание: подключение к IOU2

no shutdown
  → Включаем порт

switchport trunk encapsulation dot1q
  → Включаем инкапсуляцию 802.1Q

switchport mode trunk
  → Режим Trunk

switchport trunk allowed vlan 10,15,20
  → Разрешаем VLAN 10, 15, 20 (хотя на IOU2 только 10 и 15, но на всякий случай разрешаем все)
exit

===========================================
БЛОК 6: Настройка порта к IOU3 (Trunk)
(выполняйте все команды подряд)

ЧТО ДЕЛАЕМ: Настраиваем порт Ethernet0/2 в режим Trunk для связи с коммутатором IOU3
ЗАЧЕМ: IOU3 подключен к IOU1, нужно передавать трафик VLAN 15 и 20 между ними
===========================================
[БЛОК КОМАНД - ВСЕ ВМЕСТЕ]
interface FastEthernet0/2
  → Порт, подключенный к коммутатору IOU3
  → На роутере c7200 интерфейсы называются FastEthernet

description Connection to IOU3
  → Описание: подключение к IOU3

no shutdown
  → Включаем порт

switchport trunk encapsulation dot1q
  → Инкапсуляция 802.1Q

switchport mode trunk
  → Режим Trunk

switchport trunk allowed vlan 10,15,20
  → Разрешаем VLAN 10, 15, 20
exit

===========================================
СОХРАНЕНИЕ КОНФИГУРАЦИИ
===========================================
ВАЖНО: Сначала выйдите из режима конфигурации командой "exit"

[ОДНА КОМАНДА] exit
  → Выходим из режима глобальной конфигурации
  → Должно появиться IOU1# (привилегированный режим)

[ОДНА КОМАНДА] copy running-config startup-config
  → Сохраняем конфигурацию в постоянную память
  → БЕЗ ЭТОЙ КОМАНДЫ настройки пропадут после перезагрузки!

===========================================
ПРОВЕРКА НАСТРОЙКИ
===========================================
После сохранения можете проверить:
- show vlan brief        (покажет все созданные VLAN)
- show interfaces trunk  (покажет все Trunk порты и разрешенные VLAN)
- show interfaces status (покажет статус всех портов)
