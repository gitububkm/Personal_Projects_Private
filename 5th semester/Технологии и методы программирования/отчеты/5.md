## Теоретическая часть

### Исторические шифры перестановки

Перестановочные шифры — это класс криптографических алгоритмов, которые не изменяют символы исходного текста, а только меняют их порядок. В отличие от шифров замены, они сохраняют частоты символов, что делает их уязвимыми для частотного анализа.

**Основные свойства:**
- Сохранение частот символов
- Обратимость операции
- Простота реализации
- Историческая значимость

### Шифр Скитала

**Историческая справка:**
Скитала (греч. σκυτάλη) — древнегреческий шифр, использовавшийся спартанцами для передачи секретных сообщений. Представляет собой цилиндр с намотанной на него лентой, на которой записывался текст.

**Математическая модель:**
Текст записывается построчно в матрицу размером `rows × cols`, где `cols = ceil(len(text) / rows)`, затем считывается по столбцам.

**Алгоритм шифрования:**
1. Текст разбивается на блоки по `rows` символов
2. Каждый блок записывается в матрицу построчно
3. Матрица дополняется символами-заполнителями до полного прямоугольника
4. Текст считывается по столбцам сверху вниз

**Алгоритм расшифрования:**
1. Текст разбивается на блоки по `cols` символов
2. Каждый блок записывается в матрицу по столбцам
3. Текст считывается построчно
4. Удаляются символы-заполнители

### Решётка Кардано

**Историческая справка:**
Решётка Кардано (итал. griglia di Cardano) — шифр, изобретенный итальянским математиком Джироламо Кардано в XVI веке. Использует физический трафарет с отверстиями для записи текста.

**Математическая модель:**
Текст записывается в квадратную матрицу `n×n` через отверстия в решётке, которая поворачивается 4 раза на 90° по часовой стрелке. Каждая клетка используется ровно один раз.

**Условие корректности:**
При 4 поворотах решётки все `n²` клеток должны быть покрыты ровно один раз, без пересечений и пропусков.

**Алгоритм шифрования:**
1. Текст разбивается на блоки по `n²` символов
2. Для каждого блока:
   - Создается матрица `n×n`
   - Решётка поворачивается 4 раза
   - На каждом повороте через отверстия записываются символы
3. Матрица дополняется символами-заполнителями
4. Результат считывается построчно

**Алгоритм расшифрования:**
1. Текст разбивается на блоки по `n²` символов
2. Для каждого блока:
   - Создается матрица `n×n` и заполняется символами шифртекста
   - Решётка поворачивается 4 раза
   - На каждом повороте через отверстия считываются символы
3. Удаляются символы-заполнители

### 1. Шифр Скитала (перестановка)

#### Математическое описание

Для текста длиной `n` и количеством рядов `r`:
- Количество столбцов: `c = ⌈n/r⌉`
- Размер матрицы: `r × c`
- Количество символов-заполнителей: `r×c - n`

#### Реализация функций

**Функция шифрования:**
```python
def skytale_encrypt(text: str, rows: int, filler: str = "¤") -> str:
    if rows <= 1:
        return text
    n = len(text)
    cols = (n + rows - 1) // rows  # Округление вверх
    padded = text + (filler * (rows * cols - n))
    grid = [list(padded[i*cols:(i+1)*cols]) for i in range(rows)]
    out = []
    for c in range(cols):
        for r in range(rows):
            out.append(grid[r][c])
    return "".join(out)
```

**Функция расшифрования:**
```python
def skytale_decrypt(cipher: str, rows: int, filler: str = "¤") -> str:
    if rows <= 1:
        return cipher
    n = len(cipher)
    cols = (n + rows - 1) // rows
    grid = [[""] * cols for _ in range(rows)]
    it = iter(cipher)
    for c in range(cols):
        for r in range(rows):
            grid[r][c] = next(it, filler)
    out = "".join("".join(row) for row in grid)
    return out.rstrip(filler)
```

### 2. Решётка Кардано

#### Математическое описание

Для решётки размером `n×n`:
- Количество отверстий: `n²/4` (для покрытия всех клеток за 4 поворота)
- Каждое отверстие используется 4 раза (при 4 поворотах)
- Общее количество использований: `4 × (n²/4) = n²` ✓

#### Валидация решётки

**Функция проверки корректности:**
```python
def validate_grille(coords, n):
    """Проверяет, что при 4 поворотах покрываются все n*n клетки ровно один раз."""
    used = set()
    cur = list(coords)
    for _ in range(4):
        for cell in cur:
            if cell in used:
                return False  # Пересечение
            used.add(cell)
        cur = rotate_coords(cur, n)  # Поворот на 90°
    return len(used) == n * n  # Все клетки покрыты
```

**Функция поворота координат:**
```python
def rotate_coords(coords, n):
    """Поворот координат на 90° по часовой стрелке."""
    return [(c, n-1-r) for (r, c) in coords]
```

#### Реализация функций

**Функция шифрования:**
```python
def grille_encrypt(text: str, grille: dict, filler: str = "¤") -> str:
    n = grille["n"]
    holes = grille["holes"]
    if not validate_grille(holes, n):
        raise ValueError("Ключ-решётка некорректна.")
    out = []
    i = 0
    while i < len(text):
        block = text[i:i+n*n]
        if len(block) < n*n:
            block = block + filler * (n*n - len(block))
        grid = [[""] * n for _ in range(n)]
        idx = 0
        cur = list(holes)
        for _ in range(4):  # 4 поворота
            for (r, c) in cur:
                grid[r][c] = block[idx]
                idx += 1
            cur = rotate_coords(cur, n)
        for r in range(n):
            for c in range(n):
                out.append(grid[r][c])
        i += n*n
    return "".join(out)
```

**Функция расшифрования:**
```python
def grille_decrypt(cipher: str, grille: dict, filler: str = "¤") -> str:
    n = grille["n"]
    holes = grille["holes"]
    if not validate_grille(holes, n):
        raise ValueError("Ключ-решётка некорректна.")
    out = []
    i = 0
    while i < len(cipher):
        block = cipher[i:i+n*n]
        if len(block) < n*n:
            block = block + filler * (n*n - len(block))
        grid = [[""] * n for _ in range(n)]
        it = iter(block)
        for r in range(n):
            for c in range(n):
                grid[r][c] = next(it)
        cur = list(holes)
        chars = []
        for _ in range(4):  # 4 поворота
            for (r, c) in cur:
                chars.append(grid[r][c])
            cur = rotate_coords(cur, n)
        out.append("".join(chars))
        i += n*n
    return "".join(out).rstrip(filler)
```

### Приложение Б: Формат ключа решётки

**JSON-структура:**
```json
{
  "n": 4,
  "holes": [
    [0, 0],
    [0, 1],
    [0, 2],
    [1, 1]
  ]
}
```

**Поля:**
- `n` — размер решётки (n×n)
- `holes` — массив координат отверстий [строка, столбец]

### Приложение В: Горячие клавиши

| Действие | Горячая клавиша |
|----------|----------------|
| Копировать | Ctrl+C |
| Вставить | Ctrl+V |
| Вырезать | Ctrl+X |
| Выделить всё | Ctrl+A |
| Вставить (альтернатива) | Shift+Insert |
| Копировать (альтернатива) | Ctrl+Insert |

### Приложение Г: Ограничения и известные проблемы

**Ограничения:**
- Максимальный размер текста ограничен доступной памятью
- Для очень больших текстов (>1 МБ) может быть медленным
- Автоопределение работает лучше с русским текстом

**Известные проблемы:**
- Нет поддержки сохранения истории операций между сеансами
- Нет визуализации процесса шифрования
- Автоопределение может ошибаться на смешанных текстах
