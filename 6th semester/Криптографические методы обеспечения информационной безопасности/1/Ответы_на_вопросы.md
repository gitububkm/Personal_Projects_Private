# Ответы на вопросы для защиты лабораторной работы 1

## 1. Что изучают следующие разделы криптографии: криптология, криптография, криптоанализ?

**Криптология** - это общая наука, изучающая методы защиты информации с помощью математических преобразований. Включает в себя криптографию и криптоанализ.

**Криптография** - наука о методах преобразования информации с целью ее защиты от несанкционированного доступа. Занимается разработкой алгоритмов шифрования, создания цифровых подписей, хеширования и других криптографических методов.

**Криптоанализ** - наука о методах вскрытия шифров и криптографических систем. Занимается поиском уязвимостей, разработкой атак и оценкой стойкости криптосистем.

---

## 2. Основные отличия, определения, примеры для следующих систем: асимметричные криптосистемы, симметричные криптосистемы, криптографические протоколы.

**Симметричные криптосистемы:**
- Используют один и тот же ключ для шифрования и дешифрования
- Отправитель и получатель должны заранее обменяться секретным ключом
- Примеры: DES, AES, ГОСТ 28147, шифр Цезаря, Виженера
- Преимущества: высокая скорость работы
- Недостатки: проблема распределения ключей

**Асимметричные криптосистемы:**
- Используют пару ключей: открытый (публичный) и закрытый (приватный)
- Открытый ключ используется для шифрования, закрытый - для дешифрования
- Примеры: RSA, ElGamal, ECC (эллиптические кривые)
- Преимущества: решают проблему распределения ключей
- Недостатки: значительно медленнее симметричных

**Криптографические протоколы:**
- Набор правил и процедур, определяющих порядок использования криптографических алгоритмов для решения конкретных задач
- Примеры: TLS/SSL (защита веб-соединений), IPsec (защита сетевого трафика), протокол Диффи-Хеллмана (обмен ключами)

## 3. Выделите примеры шифров для каждого этапа развития криптографии: наивная криптография, формальная криптография, математическая криптография.

**Наивная криптография:**
- Простые методы, основанные на интуиции и опыте
- Примеры: шифр Цезаря, шифр Атбаш, скитала (Спарта)

**Формальная криптография:**
- Систематизация методов, формальное описание алгоритмов
- Примеры: шифр Виженера, роторные машины (Энигма, M209), шифр Хилла

**Математическая криптография:**
- Строгое математическое обоснование, доказательства стойкости
- Примеры: DES, AES, RSA, ECC, ГОСТ 28147, криптосистемы на основе сложных математических задач (факторизация, дискретное логарифмирование)

## 4. Шифры замены, перестановки и сдвига

**Шифры сдвига:**
- Каждый символ открытого текста заменяется символом, находящимся на фиксированном расстоянии в алфавите
- Пример: шифр Цезаря (сдвиг на 3 позиции: A→D, B→E, ...)
- Пространство ключей: ограничено размером алфавита

**Шифры замены:**
- Каждый символ открытого текста заменяется другим символом по определенному правилу
- Моноалфавитные: одна таблица замены для всего текста (шифр Цезаря, простая замена)
- Полиалфавитные: используются несколько таблиц замены (шифр Виженера)
- Пример: A→Z, B→Y, C→X, ... (произвольная перестановка алфавита)

**Шифры перестановки:**
- Символы открытого текста переставляются местами, но не изменяются
- Примеры: транспозиция по столбцам, маршрутная перестановка
- Ключ: порядок перестановки позиций

## 5. Атака полного перебора ключа и частотный анализ символов

**Атака полного перебора (brute force):**
- Метод взлома, при котором проверяются все возможные ключи до нахождения правильного
- Сложность: O(2^n) для ключа длиной n бит
- Применимость: эффективна для шифров с малым пространством ключей
- Пример: для шифра Цезаря (26 ключей) - очень быстрая атака

**Частотный анализ:**
- Метод криптоанализа, основанный на анализе частоты появления символов в шифротексте
- Принцип: в любом языке буквы имеют характерную частоту появления (например, в английском: E - 12.7%, T - 9.1%, A - 8.2%)
- Применимость: эффективен против моноалфавитных шифров
- Ограничения: менее эффективен для коротких текстов и полиалфавитных шифров

## 6. Модульная арифметика. Простые примеры.

**Модульная арифметика** - арифметика остатков от деления на фиксированное число (модуль).

**Основные операции:**
- a mod n - остаток от деления a на n
- Примеры: 17 mod 5 = 2, 23 mod 7 = 2

**Свойства:**
- (a + b) mod n = ((a mod n) + (b mod n)) mod n
- (a × b) mod n = ((a mod n) × (b mod n)) mod n
- Пример: (15 + 23) mod 7 = 38 mod 7 = 3, или (1 + 2) mod 7 = 3

**Применение в криптографии:**
- Шифр Цезаря: E(x) = (x + k) mod 26
- Дешифрование: D(y) = (y - k) mod 26

## 7. Шифр Виженера. Тест Казисского

**Шифр Виженера:**
- Полиалфавитный шифр замены
- Использует ключевое слово, которое повторяется для шифрования каждого символа
- Каждая буква ключа определяет сдвиг для соответствующей буквы открытого текста
- Пример: текст "HELLO", ключ "KEY" → "RIJVS"

**Тест Казисского:**
- Метод определения длины ключа в шифре Виженера
- Принцип: ищутся повторяющиеся последовательности символов в шифротексте
- Расстояние между повторениями кратно длине ключа
- Алгоритм:
  1. Найти повторяющиеся последовательности (обычно 3+ символа)
  2. Вычислить расстояния между повторениями
  3. Найти наибольший общий делитель (НОД) этих расстояний - это вероятная длина ключа

## 8. Принцип Кергоффса

**Принцип Кергоффса (1883):**
> "Безопасность криптосистемы должна зависеть только от секретности ключа, а не от секретности алгоритма"

**Следствия:**
- Алгоритм шифрования должен быть публичным и открытым для анализа
- Стойкость системы должна обеспечиваться только секретностью ключа
- Публичность алгоритма позволяет найти уязвимости до использования в реальных системах

**Современное применение:**
- Все современные стандарты (AES, RSA, ГОСТ) - публичные алгоритмы
- Безопасность через неясность (security through obscurity) - плохая практика

## 9. Роторные машины. Краткое описание принципа работы и внутренней структуры. Пространство ключей роторной машины.

**Принцип работы:**
- Роторные машины используют вращающиеся диски (роторы) с электрическими контактами
- Каждый ротор выполняет замену символов (как моноалфавитный шифр)
- После каждого символа роторы поворачиваются, меняя таблицу замены (полиалфавитный эффект)
- Примеры: Энигма, M209, Typex

**Внутренняя структура:**
- **Роторы**: диски с проводками, выполняющие замену
- **Рефлектор**: отражает сигнал обратно через роторы
- **Коммутационная панель (plugboard)**: дополнительная замена пар символов
- **Кольцо установки**: определяет момент переворота следующего ротора

**Пространство ключей Энигмы:**
- Выбор роторов: C(5,3) = 60 способов (из 5 выбрать 3)
- Порядок роторов: 3! = 6 перестановок
- Начальные позиции: 26³ = 17,576
- Настройки коммутационной панели: ~150,738,274,937,250
- **Общее пространство ключей**: ~10²³ (очень большое для того времени)

## 10. Криптостойкость. Вычислительная и практическая криптостойкость.

**Криптостойкость** - способность криптосистемы противостоять криптоанализу.

**Вычислительная криптостойкость:**
- Теоретическая стойкость, основанная на вычислительной сложности взлома
- Оценивается временем, необходимым для взлома при использовании лучших известных алгоритмов
- Пример: RSA основан на сложности факторизации больших чисел
- Может быть нарушена при появлении более эффективных алгоритмов или квантовых компьютеров

**Практическая криптостойкость:**
- Реальная стойкость в практических условиях
- Учитывает не только математическую сложность, но и:
  - Ресурсы атакующего (время, вычислительная мощность, деньги)
  - Стоимость защищаемой информации
  - Время жизни информации
- Пример: ключ длиной 128 бит считается практически стойким, если стоимость взлома превышает стоимость защищаемой информации

## 11. Примеры криптосистемы этапа математической криптографии.

**Характеристики математической криптографии:**
- Строгое математическое обоснование
- Доказательства стойкости (или попытки их получить)
- Основаны на сложных математических задачах

**Примеры:**

1. **DES (Data Encryption Standard, 1977)**
   - Блочный симметричный шифр
   - Основан на сети Фейстеля
   - Длина блока: 64 бита, ключ: 56 бит

2. **RSA (1977)**
   - Асимметричный шифр
   - Основан на сложности факторизации больших чисел
   - Широко используется для цифровых подписей и обмена ключами

3. **AES (Advanced Encryption Standard, 2001)**
   - Блочный симметричный шифр
   - Основан на SP-сети
   - Длина блока: 128 бит, ключи: 128/192/256 бит

4. **ГОСТ 28147-89 / ГОСТ 34.12-2015**
   - Российские стандарты блочного шифрования
   - Основаны на сети Фейстеля (Магма) и SP-сети (Кузнечик)

5. **Криптосистемы на эллиптических кривых (ECC)**
   - Основаны на сложности дискретного логарифмирования на эллиптических кривых
   - Обеспечивают ту же стойкость при меньшей длине ключа

## 12. Криптоанализ. Классический криптоанализ. SCA.

**Криптоанализ** - наука о методах вскрытия шифров и криптографических систем.

**Классический криптоанализ:**
- Методы анализа, основанные на математических свойствах алгоритмов
- Типы атак:
  - **Атака на основе только шифротекста** (ciphertext-only)
  - **Атака на основе известного открытого текста** (known-plaintext)
  - **Атака на основе выбранного открытого текста** (chosen-plaintext)
  - **Атака на основе выбранного шифротекста** (chosen-ciphertext)
- Методы: частотный анализ, дифференциальный криптоанализ, линейный криптоанализ

**SCA (Side-Channel Analysis) - анализ побочных каналов:**
- Атаки, использующие информацию, получаемую не из алгоритма, а из физической реализации
- Типы:
  - **Анализ времени выполнения** (timing attacks)
  - **Анализ энергопотребления** (power analysis)
  - **Анализ электромагнитного излучения** (EM analysis)
  - **Анализ ошибок** (fault analysis)
- Защита: постоянное время выполнения, маскирование, рандомизация

**Примеры:**
- Классический: частотный анализ шифра Цезаря
- SCA: измерение времени выполнения операции модульного возведения в степень для взлома RSA
